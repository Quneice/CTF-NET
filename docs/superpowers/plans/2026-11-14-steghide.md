# steghide 图片隐写解码(misc.steghide)Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans or subagent-driven-development.

**Goal:** misc 新增 steghide 外挂工具:空密码探测/指定密码/字典爆破三模式提取 JPG/BMP/WAV 隐藏数据。

**Architecture:** fscan 同款外挂模式——settings 加 `Tools.Steghide`(默认 `C:\Users\HP\Downloads\steghide\steghide.exe`)+ `core.ToolPath("steghide")`;Runner 内逐密码 `tc.Executor.Run` 调 `steghide extract -sf -p -xf -f`(exit 0 + 文件生成 = 命中即停);报告 markdown + artifact。

**Spec:** `docs/superpowers/specs/2026-11-14-steghide-design.md`(CLI 语义已实测:空密码可用;成功 "wrote extracted data";失败 "could not extract any data with that passphrase";exe+cygwin DLL 部署于 Downloads\steghide\ 并验证 --version 0.5.1)

## Global Constraints

- 常见密码含空格/引号:经 Executor 数组传参不经 shell,天然安全;报告中密码原样转义展示。
- 字典上限 10 万行;单次提取超时 60s;exe 缺失 → StatusError 给指引(路径/获取方式)。
- live 测试门控:exe 存在才跑(fixture 现场用 embed 造);不存在 Skip。
- 提交中文 + Co-Authored-By;README/设置页/工具条目同步;exe 重建。

## Review Focus

1. 空/错密码判定准确性(exit code + 输出文件双条件,防 steghide 行为差异)→ live 测试钉死。
2. exe 缺失/损坏路径的友好指引 → helper 级测试钉死(可注入路径)。
3. 字典大文件逐行流式读取 + 上限截断 → 测试(超限行数报告)。
4. 提取内容分类与预览(二进制安全,不乱码)→ live 断言 artifact 字节一致。
5. 设置链路(ToolPath case/默认值/设置页行)→ grep 断言三处一致。
